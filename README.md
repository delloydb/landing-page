Overview
This is my first practice project using HTML and CSS with a focus on mastering divs and Flexbox layout. I created this as part of my web development learning journey, following the design principles I've been studying.

Pure HTML/CSS implementation - No JavaScript or frameworks used

Responsive design - Works on different screen sizes

Flexbox layout - Demonstrates my understanding of Flexbox concepts

Semantic HTML - Proper use of semantic tags where appropriate

Clean styling - Organized CSS with variables for consistency

Implementing Flexbox for layout management

Creating responsive designs with media queries

Styling buttons and interactive elements

Working with CSS variables for consistent theming

Proper spacing and alignment techniques
